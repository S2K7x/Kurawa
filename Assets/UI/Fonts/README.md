# Polices

- **Cinzel.ttf** — titres et noms de guerriers (serif à capitales, style "grimoire de guilde").
  Cinzel Project Authors, licence SIL Open Font License 1.1 (`OFL-Cinzel.txt`).
- **Inter.ttf** — corps de texte, boutons, chiffres. Rasmus Andersson, licence SIL OFL 1.1 (`OFL-Inter.txt`).

Les deux sont des polices variables : l'axe de graisse se règle dans Godot via
`variation_opentype` sur la ressource FontVariation (voir `kurawa_theme.tres`).
Redistribuables avec le jeu tant que les fichiers OFL restent présents.
